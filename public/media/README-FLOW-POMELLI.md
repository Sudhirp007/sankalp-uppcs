# Flow & Pomelli Media Drop-In Guide (`mockexamonline.com`)

Drop your exported Google Labs **Flow** (AI cinematic motion/video) and **Pomelli** (on-brand campaign creatives) assets into this `public/media/` folder using the filenames below. The Landing Page (`PublicMarketingApp.tsx`) automatically detects and renders them with zero code changes:

1. `public/media/flow-hero.mp4` — Loops silently inside the Hero Cinema Showcase frame on `mockexamonline.com/` (falls back gracefully to the interactive Live UPPSC Cockpit Simulator until added).
2. `public/media/flow-hero-poster.webp` — Instant LCP poster thumbnail for `flow-hero.mp4` (1280×720 recommended, `<120 KB`).
3. `public/media/pomelli-campaign-1.webp` — Featured visual card #1 in the Brand Visuals / Aspirant Transformation showcase.
4. `public/media/pomelli-campaign-2.webp` — Featured visual card #2 (e.g., 50-50 Elimination & Mistake SRS visual story).
5. `public/media/og-cover.jpg` — 1200×630 OpenGraph social share card used automatically on WhatsApp, Telegram, X/Twitter, and LinkedIn shares across `mockexamonline.com`.
